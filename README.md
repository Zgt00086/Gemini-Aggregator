# <span class="emoji emoji1f4f1"></span> 全能系统管家 (AIO-KSU-Toolbox)<br/><br/>这是一个基于 KernelSU / APatch WebUI 机制打造的 **All-In-One (AIO) 极客聚合模块**。<br/><br/>本项目致力于打造一个零耗电、零卡顿、极具交互美学的“全能底座”。彻底抛弃了传统的“终端黑框框”和“物理音量键盲操”，为你带来 HyperOS / MIUIX 级别原生、直观的可视化系统控制台。<br/><br/>## <span class="emoji emoji2747"></span> 核心特性 (Core Features)<br/><br/>* **🛡️ 系统更新屏蔽器**：通过底层物理挂载空文件（`mount --bind`）彻底冻结系统更新组件，支持防误触 Toast 提示与重启持久化状态明示。<br/>* **<span class="emoji emoji26a1"></span> Smart DexOpt 引擎**：采用原生 V4 引擎深度扫描。摒弃 Java 层命令，纯 Native C++ 底层排查，无死角掌控全量应用编译状态（speed/speed-profile/verify/run-from-apk）。<br/>* **🧩 模块跳转中心**：一键聚合本机所有 KSU 模块，内嵌滚动视图与排序算法，直达 MT 管理器对应目录。<br/>* **<span class="emoji emoji1f47b"></span> 后台静默守护中心**：内置零耗电的开机自启脚本（如 Gemini 唤醒自动修复），在 WebUI 底部静默展示，绝不干扰主视觉。<br/><br/>## 🛠️ 独家底层架构 (致敬踩过的坑)<br/><br/>本底座攻克了 WebUI 模块开发中的三大绝症，为后续的插件融合打下了坚如磐石的基础：<br/><br/>1.  **突破 4KB 管道截断**：长篇数据回传不再使用 `stdout` 直出，而是采用 `Base64` 封包流式传输，前端 `atob` 瞬间解码，哪怕装了 1000 个应用也绝不漏扫。<br/>2.  **免疫环境丢失（脱管防瞎）**：彻底抛弃依赖 Java 虚拟机（`app_process`）的 `pm` 命令，改为纯 C++ 原生命令（`cmd package`），确保 `nohup` 挂入系统后台后依然能精准抓取数据。<br/>3.  **UI 异步非阻塞切片**：所有的底层高压查询全部转移至后台守护进程，前端通过 `setInterval` 轻量级轮询。彻底告别“点击按钮后屏幕卡死 15 秒”的噩梦，滑动丝滑如水。<br/><br/>---<br/><br/>## <span class="emoji emoji1f468"></span>‍<span class="emoji emoji1f4bb"></span> 开发者/AI 协作指南：如何无缝融合新模块？<br/><br/>本模块采用了极高扩展性的积木式架构。如果你（或者你正在使用的 AI）想要往本模块中添加新功能，**请严格遵循以下 SOP（标准开发规范）**！<br/><br/>### <span class="emoji emoji1f4a1"></span> 模块融合 AI 唤醒咒语<br/><br/>如果你想让 AI 帮你写新功能，请直接复制以下内容发送给 AI：<br/><br/>> **【AIO 聚合管家 -
